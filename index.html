What it is

The premise

Most AI chat apps send every question — and whatever data answers it — to a hosted model behind an API key. This lab takes the cloud model away. A small open model runs on your machine through Ollama, and the data it talks about sits in a SQLite file beside it.

The model knows nothing about that data. It is not trained or fine-tuned on it. Every fact about a customer reaches it through a tool call, at the moment it is asked, so the data can change without retraining and every answer can be traced to a query.

The data belongs to Checkpoint Outfitters, a fictional adventure-racing gear shop. Three panes show the work: the chat, a live activity log down to the SQL, and a customer-service rep screen drawn from tool results — never from the model's own words.

What "locked down" means — and does not

What the model can reach is fixed by architecture: six read-only MCP tools, a database opened read-only, no SQL tool, no network. What it says is shaped by three guardrail layers, and those are weaker — the page will say how much weaker, measured, once the model eval has run.
